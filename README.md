# RO’Lyfe Family Wealth & Trading Academy™

Mobile-first Phase 1 foundation for a private family learning and simulated trading workspace.

## What's included
- Responsive overview dashboard
- $10,000 virtual starting cash
- Manual hypothetical-price stock simulator
- Open and close simulated long positions
- Basic risk preview based on entry, stop, shares, and available cash
- Local trade history and journal notes
- Starter learning curriculum
- No broker connection, no real orders, and no live market data

## Run it
Open `index.html` in a modern browser, or publish this folder as a separate GitHub Pages repository.

## Important limits
- Data is stored in the current browser using `localStorage`; it is not synced across devices or users.
- This foundation does not fetch prices. All prices are entered manually for practice.
- It currently models stock shares only, not options contracts.
- A simulated close records the closing proceeds and tracks trade history. This is a learning prototype, not an accounting or tax system.
- Risk preview is educational and does not guarantee a maximum realized loss.
- Do not enter brokerage credentials or real account information.
